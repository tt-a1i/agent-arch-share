# 资料范围与公开发布说明

- 当前 GitHub 仓库是 **public**；任何合入的文件均可能被公开索引。
- 本目录提供可审阅的**研究性整理**，不是 ChatGPT 全量逐字聊天导出。
- 先前 V1–V11 研究资料库含 63 份 Markdown；目前仅挑选非逐字、非敏感的主题摘要进入 GitHub PR，完整压缩包仍在当前对话文件中。
- 个人项目实践被抽象为技术描述，不包含屏幕截图原始数据、私人聊天正文、密钥、客户数据或他人的私人信息。
- 付强老师问题来源于用户提供的转写整理，而非经核验的逐字录音；在公开材料中引用时需标注这一点。
- 不将讨论中的推测、产品形态预测和消融计划写成已证实结果。
- 若计划上传**逐字聊天记录**，应先从 ChatGPT 正式导出，并对私人对话、第三方信息、凭据和内部信息进行单独审查。
