# 研究讨论时间线与观点（整理版）

> 这是根据连续讨论提炼的纪要，**不是逐字聊天记录**。除引用外，表述为双方讨论后的概括。

## 1. 研究起点：智能增长与协作增长

面试中的开放问题：过去二十年计算、存储和互联网平台规模大幅增长，为何多人在线游戏单局规模未必同幅增长？可能涉及实时交互、共享状态、一致性、通信和产品形态的共同作用；不能简单归因于单一通信瓶颈。

将该问题延伸至多 Agent：单个 Agent 更聪明、更快，不意味着十个、一百个 Agent 的有效产出同比增加。应区分单体任务能力、多 Agent 协作效率、人机协作的注意力与监督成本。

## 2. 人的注意力

用户质疑：将五个 Session 合并为一个入口，仍需要理解五个不同项目。**入口管理成本**不等于**任务认知切换成本**。Agent 更自主，可能减少执行参与，也可能增加出问题时的人类上下文恢复成本。

## 3. Session 边界与记忆

单长 Session 能沿用历史，但存在无关上下文混入、阻塞和输入成本；多 Session 有并发与隔离优势，却带来共享背景重复加载、知识迁移和恢复成本。讨论了项目级文件、任务状态、共享记忆、Inline & Spill、Chain of Recall，以及根据任务关系选择复用/隔离的可能性。这些方案需要验证，不预设优劣。

## 4. Router / Worker

Hive、Codex App 与 Super-agent 都采用过一对多执行组织。DeepSeek 的贡献更侧重事件驱动、长生命周期运行、任务状态与执行环境分离等 Runtime 工程整合，不能仅凭命名就视为全新协作范式。

用户倾向于给 Router 使用强模型；需要区分 **Router 的模型智能能力** 与 **Router 实际承担的任务职责**。简单事件由确定性规则和订阅关系路由；涉及人类问答、跨任务冲突或复杂判断时，Router 可以适度深入；耗时执行可委派。最优边界取决于质量、延迟、成本和系统负载。

## 5. 事件过滤、Pass-through 与通信成本

已知 Thread 与 Worker 的订阅关系可以用于代码直通；CI 成功也可能需要通知等待结果的 Worker，因此不能一律丢弃。绕过 Router 模型判断一般能减少路由调用，却不能免除 Worker 对消息的理解和执行。

无 Pass-through 的额外 Router Turn 可能反复读取缓存前缀，增加 Cache-read Tokens。实验中模型开销增加但任务完成时间几乎不变，可能因为 Router 不是关键路径瓶颈且存在批处理。**缓存读取 Token 增量不等于实际费用增量，也不等于 Reasoning Token 增量。**

## 6. Pub/Sub 与协调瓶颈

多个 Worker 订阅同一 Thread 可以共享事件，却不能保证版本一致、行动协调或冲突解决。若 Worker 不直接协作，未解决的跨任务冲突可能集中到 Router：信息汇总失真、任务重派、全局记忆矛盾。需要在独立任务与强耦合任务上比较中心协调、直接通信与混合策略。

## 7. 全双工、Daemon、Watchdog

异步工具执行改善会话非阻塞交互，但**快速响应**不等于**新指令已经安全生效**。云端 Agent Loop、持久 Session 状态、本地 Mac Daemon 可以分离设计；设备离线可能仍使依赖本机的操作暂停。

Watchdog 可独立检查基础设施健康及语义级任务进展，也可能与已有“系统观察员”角色相似。需要比较规则监控、Worker 自检、独立监督 Agent、主动修复等策略，注意误报与授权边界。

## 8. 实验、消融与评估

讨论的共识：系统设计是实现目标的手段，不存在脱离负载的绝对最优。关注真实任务成功率、质量、人工介入、Token 和基础设施总成本、延迟、恢复成本、错误率；通过对照与消融识别组件的独立贡献。

## 9. 组织协作与个人工作记录

传统组织信息散落在群聊、会议、私聊、工具、线下沟通和人的隐含认知中。只同步 IM 和会议纪要难以恢复完整项目状态。个人侧工作记录（macOS 无障碍信息，必要时截图，输入框内容与 Agent Session 线索）可能形成补充，但**工作活动不等于真实进展**。

未来可能让个人侧在授权下生成带证据的候选任务状态，项目系统验证后再用于协调。跨 Agent 的知识共享、执行授权、决策权与责任边界需要分别设计，不能自动等同。

## 未解研究问题

- Router 的适宜推理深度与执行职责边界如何随负载变化？
- Worker 直接通信与中心协调的冲突处理成本如何变化？
- 固定隔离、共享项目上下文、动态上下文边界哪种适合哪些任务？
- 个人工作记录是否能够低成本改善项目状态的准确性与时效性？
- 在组织中，Agent 如何代表不同主体进行受控协作而不越权？
