## 用于 PPT 的原则

- 作者原文、个人实践、讨论推论、待验证假设必须清晰标注。
- 不宣称某种架构绝对优于另一种；比较目标、质量、成本、延迟、适用边界。
- 不能把“统一入口”直接等同于“消除人类认知切换”。
- 不能把“共享事件”直接等同于“协调一致”。
- 不将模拟工作负载实验解释为真实开发任务质量提升。
- 后续 PPT 修改建议通过独立 PR 审阅。
